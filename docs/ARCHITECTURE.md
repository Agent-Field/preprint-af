# Architecture — preprint-af

This document describes the module layout, data models, workspace structure, and the
framework behaviors the code relies on. `src/preprint_af/reasoners/models.py` defines all the
Pydantic models referenced below.

## 1. Mission

Given any research folder (raw data, results, notebooks, a markdown draft, or an existing
paper), produce a complete, compiled LaTeX paper with:
- strategically chosen positioning (the same results can be framed as speed, memory,
  mechanism, reliability, benchmark...; a tournament picks the highest-impact honest frame),
- real figures generated by running scripts against the actual data,
- `\todobox{...}` boxes in the paper plus `TODO.md` for missing experiments/data,
- prose that reads like a top human scientist wrote it (no AI-slop patterns),
- iterative critique/repair rounds that run until convergence criteria are met.

## 2. Framework facts (agentfield 0.1.96)

1. `router.harness(prompt, *, schema=None, provider="opencode", model=None, cwd=None,
   project_dir=None, schema_mode=None, system_prompt=None, ...) -> HarnessResult`.
   For the **opencode** provider: `max_turns`, `max_budget_usd`, `tools`, `permission_mode`
   are silently ignored. The only real cap is the wall-clock timeout
   (`AGENTFIELD_HARNESS_TIMEOUT_SECONDS`, default 1800s). Do not pass or rely on those options.
2. `HarnessResult` fields: `result` (raw text), `parsed` (validated schema instance or None),
   `is_error`, `error_message`, `failure_type`, `cost_usd`, `num_turns`, `duration_ms`,
   `session_id`, `messages`, property `.text`. There is NO `files_changed` field —
   observe file changes from disk/git yourself.
3. No harness session resume for opencode. All state between calls lives on disk in the
   workspace. Each call is a fresh OpenCode subprocess.
4. OpenCode natively reads `AGENTS.md` from the directory passed as `project_dir`.
   The workspace root's AGENTS.md is our style/fidelity contract — every harness call
   MUST set `project_dir` to the workspace root so it is picked up.
5. Concurrency: OpenCode subprocesses are capped at 10 process-wide (env
   `OPENCODE_MAX_CONCURRENT`). `asyncio.gather` over many harness calls is safe.
6. `router.ai(system=..., user=..., schema=Model, model=...)` — litellm-backed. Model
   strings need a provider prefix (`openrouter/deepseek/deepseek-v4-pro`). On schema-parse
   failure it retries twice then RAISES. Every `.ai` call must be wrapped in try/except
   with a safe fallback object (`confident=False`).
7. `router.call("node.reasoner", **kwargs)` always goes over HTTP through the control
   plane and always returns a plain dict — reconstruct Pydantic models on the receiving
   side with `Model(**payload)`. Pass FILE PATHS between reasoners, never document bodies.
8. Reasoner naming: a function `foo` on `AgentRouter(prefix="bar")` is callable as
   `f"{node_id()}.bar_foo"`. `node_id()` comes from `helpers.py`.
9. The entry is driven via the async endpoint
   (`POST /api/v1/execute/async/<node>.<reasoner>`); the sync endpoint dies at 90s.

## 3. Defaults

- `DEFAULT_MODEL = "openrouter/deepseek/deepseek-v4-pro"` for both `.ai()` and OpenCode.
  Read from env: `AI_MODEL` / `OPENCODE_MODEL` with this fallback.
- Every reasoner accepts `model: str | None = None` and threads it into `.ai(model=model)`
  and `.harness(model=model or os.getenv("OPENCODE_MODEL", DEFAULT_MODEL))`.
- Node id: `os.getenv("AGENT_NODE_ID", "preprint-af")`.

## 4. Workspace layout (single source of truth)

Created under `<project_root>/.tmp/runs/<run_id>/`:

```
workspace root (= Workspace.root)
├── AGENTS.md               # style + fidelity contract, auto-read by OpenCode
├── EVIDENCE.md             # P0 output: fact ledger with ids E1..En, provenance, numbers
├── POSITIONING.md          # P1 output: winning frame, final title/abstract, rejected frames
├── BLUEPRINT.md            # P2 output: section beats, transition contract, figure plan
├── TODO.md                 # accumulated missing-experiment/data items
├── REVIEW.md               # final unresolved problems (written at the end)
├── STATE.json              # phase/round state, scores
├── input/                  # read-only copy of the user's folder
├── paper/
│   ├── main.tex            # skeleton; \input's sections; defines \todobox env
│   ├── refs.bib
│   ├── CITATIONS_LOG.md    # every added citation + source URL/DOI for audit
│   ├── sections/NN_slug.tex
│   └── figures/<slug>.py, <slug>.pdf
└── reviews/round_N/        # persona/narrative/fidelity/slop reports as .md + .json
```

The workspace root is `git init`-ed at creation; each phase/round ends with a best-effort
commit (`git_snapshot`). This gives diffability, auditability, and rollback to best round.

## 5. Module contract

All files in `src/preprint_af/reasoners/`. Each module creates `router = AgentRouter(prefix="<prefix>", tags=[...])`
and only the listed reasoners. Helper functions in modules are plain functions (no decorator).
Reasoners return Pydantic instances (agentfield serializes them); callers reconstruct from dicts.

### 5.2 `intake.py` — `AgentRouter(prefix="intake")`

```python
@router.reasoner()
async def prepare_workspace(folder_path: str, model: str | None = None) -> Workspace
    # deterministic: helpers.create_workspace

@router.reasoner()
async def build_evidence_ledger(workspace: dict, model: str | None = None) -> EvidenceSummary
```
`build_evidence_ledger` = ONE harness call, `cwd`/`project_dir` = workspace root. Prompt:
explore `input/` exhaustively (data files, notebooks, drafts, PDFs, figure scripts, logs);
write `EVIDENCE.md` with sections: `## Facts` (each `### E<n>` with statement, exact
numbers, source file paths, how derived), `## Figure candidates` (what plots the actual
data supports, with source files), `## Gaps` (experiments/data missing for stronger claims —
phrased as TODO items), `## Existing draft` (assessment if one exists), `## Citation
inventory` (every bib entry / cited work found in input). Rules: never invent a number;
if a value can be computed from data files with a trivial script, compute it
(python available at `figure_python()` path) and record the derivation. Schema:
`EvidenceSummary`. On harness error: return `EvidenceSummary(confident=False, draft_assessment=<error>)`.

### 5.3 `positioning.py` — `AgentRouter(prefix="positioning")`

```python
@router.reasoner()
async def generate_frames(workspace: dict, target_venue: str | None = None,
                          field_hint: str | None = None, model: str | None = None) -> FrameSet
@router.reasoner()
async def judge_frame(frame: dict, evidence_digest: str, persona: str,
                      target_venue: str | None = None, model: str | None = None) -> FrameJudgment
@router.reasoner()
async def scan_novelty(workspace: dict, frame_set: dict, model: str | None = None) -> NoveltyScan
@router.reasoner()
async def run_positioning(workspace: dict, target_venue: str | None = None,
                          field_hint: str | None = None, allow_web: bool = True,
                          model: str | None = None) -> PositioningDecision
```
- `generate_frames`: `.ai()` with FULL `EVIDENCE.md` text (read from disk, cap 60k chars) —
  produce 5–6 genuinely different frames; each frame must include a CONCRETE `title` and
  `mini_abstract` (~120 words) written in that frame, because judges score artifacts,
  not descriptions. Frames must differ in what they make primary (angle), not wording.
- `judge_frame`: `.ai()`; personas judge title+mini_abstract for comprehension, excitement,
  credibility, and NATURALNESS (would a senior human scientist write this? penalize
  colon-stacking, keyword packing, hype, generic "novel framework" phrasing).
- `scan_novelty`: harness call (only when allow_web) — OpenCode with `project_dir`=workspace
  root: web-search closest related work for the top frames (arXiv, Semantic Scholar,
  Google Scholar); write `POSITIONING_SCAN.md` (closest titles, how they position, collision
  risks, open angles). Schema `NoveltyScan`. On error → `NoveltyScan(confident=False)`.
- `run_positioning` (orchestrator): frames = generate_frames → take top 4 by
  `0.55*evidence_alignment + 0.45*impact_potential` → `asyncio.gather` judge_frame for
  each (frame × persona) pair with 4 personas:
  domain expert / skeptical methods reviewer / interdisciplinary editor / busy area chair.
  Run scan_novelty concurrently with the judging gather. Then one `.ai()` meta-selection
  (input: frames, judgments, novelty scan) → `PositioningDecision` with `final_title`,
  `final_abstract` (full ~180-word abstract, not the mini), `opening_thesis`,
  `contribution_order`. Write `POSITIONING.md` (winner + rationale + per-frame judgment
  table + rejected alternatives + novelty scan digest). Positioning runs ONCE per run.

### 5.4 `blueprint.py` — `AgentRouter(prefix="blueprint")`

```python
@router.reasoner()
async def design_blueprint(workspace: dict, target_venue: str | None = None,
                           model: str | None = None) -> Blueprint
```
`.ai()` with EVIDENCE.md + POSITIONING.md (+ venue/field): produce `SectionSpec`s
(6–9 sections typical: intro, related work, method, experimental setup, results,
discussion, conclusion — adapt to evidence and venue; slugs are file slugs) with ordered
`beats`, the transition contract (`establishes`/`requires` chain must be consistent:
section N's `requires` ⊆ section N-1's `establishes`), `evidence_ids` per section, and
`FigureSpec`s where every `buildable=True` figure names real files in `input/` as
`data_sources`. Also `citation_needs`. Write `BLUEPRINT.md` (human-readable render).
Then deterministically write `paper/main.tex` via `helpers.main_tex_skeleton` (title +
abstract from POSITIONING decision passed in via workspace read of POSITIONING.md — the
orchestrator passes decision fields; see workflow) and empty placeholder section files
are NOT created (writers create them). Fallback on .ai failure: raise ValueError with a
clear message (the entry reasoner surfaces it) — a paper cannot proceed without a blueprint.

Note: to keep the reasoner signature simple, `design_blueprint` receives `workspace` and
reads POSITIONING.md itself from disk, and writes main.tex itself.

### 5.5 `build.py` — `AgentRouter(prefix="build")`

```python
@router.reasoner()
async def write_section(workspace: dict, section: dict, prev_section: dict | None,
                        next_section: dict | None, model: str | None = None) -> WorkerResult
@router.reasoner()
async def build_figure(workspace: dict, figure: dict, model: str | None = None) -> WorkerResult
@router.reasoner()
async def build_bibliography(workspace: dict, citation_needs: list[str],
                             allow_web: bool = True, model: str | None = None) -> WorkerResult
@router.reasoner()
async def run_build(workspace: dict, blueprint: dict, allow_web: bool = True,
                    model: str | None = None) -> BuildReport
```
- `write_section`: ONE harness call. cwd/project_dir = workspace root. The prompt gives:
  the section's spec (heading, beats, establishes/requires, evidence_ids, figure_slugs,
  target_words), the neighbors' `establishes`/`requires` (transition contract), and
  INSTRUCTS the agent to read EVIDENCE.md, POSITIONING.md, BLUEPRINT.md and relevant
  input/ files itself, then write ONLY `paper/sections/<NN>_<slug>.tex` (NN = zero-padded
  index). Content rules: no `\section` command mismatch with blueprint heading; use only
  evidence-backed numbers (cite fact ids in a trailing `% E<n>` comment on the line);
  `\todobox{...}` where data is missing; cite only keys that exist in refs.bib OR use
  `\todobox` for needed-but-unknown citations; follow AGENTS.md style contract. Schema:
  `WorkerResult`. After the call, verify the file exists and is non-trivial (>300 chars);
  else status="failed".
- `build_figure`: ONE harness call per buildable figure. Write `paper/figures/<slug>.py`
  that loads the REAL data from `input/...` (paths in spec), produces
  `paper/figures/<slug>.pdf` (and .png), run it with the python at `figure_python()`
  (pass the absolute interpreter path in the prompt), fix errors until it runs, verify the
  pdf exists. Numbers/series must come from the data files or EVIDENCE.md-recorded values —
  hardcoding literals is allowed ONLY if each is annotated with a comment naming its
  EVIDENCE.md fact id. Non-buildable figures: do NOT call harness; append a TODO via
  `append_todos` and return WorkerResult(status="todo").
  After call: verify `<slug>.pdf` exists else status="failed".
- `build_bibliography`: ONE harness call. Consolidate bib entries found in `input/` into
  `paper/refs.bib`; for `citation_needs` items, if `allow_web` search the web (arXiv /
  Semantic Scholar / publisher pages) and add ONLY verified-real entries, each logged in
  `paper/CITATIONS_LOG.md` with its URL/DOI; anything unverifiable becomes a TODO. If not
  allow_web: only input-derived entries, needs → TODO.md.
- `run_build` (orchestrator): reconstruct Blueprint; `asyncio.gather` ALL of: every
  write_section (with neighbor specs), every build_figure, and build_bibliography —
  via `router.call` so the DAG is recorded. The OpenCode semaphore (10) does the throttling.
  Collect into `BuildReport`; `confident` = all sections done + bib not failed.

### 5.6 `latex.py` — `AgentRouter(prefix="latex")`

```python
@router.reasoner()
async def compile_paper(workspace: dict, model: str | None = None) -> CompileReport
```
Loop up to 3 attempts: `helpers.run_latexmk`; on failure, ONE harness call (cwd =
paper dir, project_dir = workspace root): "compilation failed, here is the filtered log
excerpt <...>; fix LaTeX errors ONLY — do not change scientific content, numbers,
citations, or prose meaning; likely causes: missing packages (prefer removing the

Return CompileReport(success, attempts, pdf_path, error_excerpt).

### 5.7 `critique.py` — `AgentRouter(prefix="critique")`

```python
PERSONAS: list[str]  # module constant, 4 entries (domain expert, skeptical methods+stats,
                     # venue editor for engagement/first-page impact, careful-reader for
                     # equations/figures/flow)
@router.reasoner()
async def persona_review(workspace: dict, persona: str, round_no: int,
                         model: str | None = None) -> PersonaReview
@router.reasoner()
async def narrative_review(workspace: dict, round_no: int, model: str | None = None) -> NarrativeReview
@router.reasoner()
async def fidelity_audit(workspace: dict, round_no: int, model: str | None = None) -> FidelityAudit
@router.reasoner()
async def run_critique(workspace: dict, round_no: int, model: str | None = None) -> CritiqueBundle
```
- All read the FULL assembled paper via `helpers.assemble_paper_text` (cap 90k chars) —
  NOT snippets.
- `persona_review` (.ai): located issues (`section` = slug); major = would block acceptance.
- `narrative_review` (.ai): reads POSITIONING.md too; checks section-to-section transitions
  against the blueprint contract, abstract/title promise vs body delivery, story arc.
- `fidelity_audit` (.ai): reads EVIDENCE.md too; every quantitative claim in the paper must
  trace to a fact id or sit inside a \todobox; flags invented citations (keys not in
  refs.bib), number mismatches. Sets `blocking=True` on real drift.
- `run_critique`: gather personas × persona_review + narrative_review + fidelity_audit
  (all parallel, via router.call) + deterministic `helpers.slop_lint` (called directly,
  not a reasoner). Write `reviews/round_<N>/` artifacts: one .md per persona +
  narrative.md + fidelity.md + slop.md (validated JSON dumps alongside). Return
  CritiqueBundle.

### 5.8 `repair.py` — `AgentRouter(prefix="repair")`

```python
@router.reasoner()
async def plan_repairs(workspace: dict, critique: dict, model: str | None = None) -> RepairPlan
@router.reasoner()
async def apply_repairs(workspace: dict, plan: dict, model: str | None = None) -> int  # applied count
```
- `plan_repairs` (.ai): route critique findings into at most 8 `RepairTask`s. Group by
  `target` (one task per section slug max; `front_matter` = title/abstract/main.tex;
  `figures`; `bibliography`). Fidelity issues → priority high, always included. Slop
  violations are passed with file/line for mechanical fixing. If nothing is worth fixing
  return an empty task list (this signals convergence).
- `apply_repairs`: front_matter task (if any) runs FIRST alone (touches main.tex), then
  all section/figure/bib tasks in parallel via harness (each prompt: your ONLY writable
  file(s) = <target files>; apply these instructions; obey AGENTS.md; never change
  evidence-backed numbers unless the instruction says the number is wrong per EVIDENCE.md).
  Returns number of tasks that completed (verify with git_changed_files / file mtimes;
  a task whose harness call errored counts as not applied).

### 5.9 `workflow.py` — `AgentRouter(prefix="")`

```python
@router.reasoner(tags=["entry"])
async def write_paper(folder_path: str, target_venue: str | None = None,
                      field_hint: str | None = None, max_rounds: int = 6,
                      allow_web: bool = True, dry_run: bool = False,
                      quality_threshold: float = 0.90, plateau_delta: float = 0.01,
                      model: str | None = None) -> dict
```
Flow (every cross-module step via `await router.call(f"{node_id()}.<name>", ...)`,
reconstructing models from dicts; `git_snapshot` + `save_state` after each phase):

1. P0: `intake_prepare_workspace` → `intake_build_evidence_ledger`.
2. P1: `positioning_run_positioning` (once).
3. P2: `blueprint_design_blueprint`.
4. If `dry_run`: return WriteResult(status="planned", ...).model_dump() now.
5. P3: `build_run_build`. Then P4: `latex_compile_paper`.
6. Convergence loop — runs until criteria met (user requirement), with `max_rounds` as a
   pure safety cap:

```
prev_score, no_improve, best = None, 0, (-1.0, None)
for round_no in 1..max_rounds:
    bundle   = critique_run_critique(round_no)
    scores:  persona_score  = 1 - mean(acceptance_risk)
             narrative_score= bundle.narrative.score
             fidelity_score = bundle.fidelity.score
             slop_score     = bundle.slop.score
             total = .35*persona + .25*narrative + .25*fidelity + .15*slop
    compile_ok = last CompileReport.success
    git_snapshot(root, f"round {round_no} critique, score={total:.3f}")
    if total > best[0]: best = (total, round_no)
    converged = compile_ok and total >= quality_threshold and not bundle.fidelity.blocking
    if converged: stop "quality_threshold_met"
    if prev_score is not None and (total - prev_score) < plateau_delta:
        no_improve += 1
        if no_improve >= 2: stop "quality_plateau"
    else: no_improve = 0
    plan = repair_plan_repairs(bundle)
    if not plan.tasks: stop "no_repairs_needed"
    applied = repair_apply_repairs(plan)
    compile  = latex_compile_paper()          # gate again after edits
    if not compile.success: git revert not needed; next critique will see it, but record compile_ok
    prev_score = total
else: stop "safety_cap_reached"
```
7. Write `REVIEW.md` (unresolved: remaining major issues from last bundle, fidelity flags,
   slop residue, TODO digest) and return `WriteResult(...).model_dump()` with rounds,
   final pdf path, title (from POSITIONING.md front matter), stop_reason.

Record a `RoundRecord` per round. `fidelity.blocking` NEVER silently passes: while
blocking, converged=False and fidelity repairs are priority-high (plan_repairs handles it).

## 6. AGENTS.md style contract (helpers.style_contract_markdown)

Must contain, in this order (concise imperatives, no fluff):
1. **Role**: you are writing/editing one artifact of a scientific paper inside this
   workspace; touch ONLY the files your prompt assigns.
2. **Fidelity rules**: every number/claim traces to an EVIDENCE.md fact id (`% E<n>`
   comment); no invented results, datasets, metrics, citations, or figures; missing
   material → `\todobox{what is needed and why}`; cite only keys present in `paper/refs.bib`.
3. **Prose rules (hard bans)**: NO em dashes (—) or ` --- ` in prose, use commas, periods,
   or parentheses; banned words/phrases: "delve", "showcase", "underscore(s)", "pivotal",
   "crucial role", "paradigm", "cutting-edge", "comprehensive framework", "novel approach"
   (as a phrase), "it is worth noting", "in conclusion", "moreover" more than once per
   section, "furthermore" more than twice per paper, "not only ... but also",
   "leverag(e|ing)" more than once per paper; no rhetorical questions; no exclamation marks.
4. **Prose rules (positive)**: open paragraphs with a claim, contrast, mechanism, or
   result; vary sentence length deliberately (mix short declaratives with dense technical
   sentences); concrete verbs and domain nouns over evaluative adjectives; hedge only with
   calibrated uncertainty tied to evidence; write transitions that carry scientific
   content, not signposts.
5. **Structure rules**: no `\subsubsection`; subsections only for real method/experiment
   families; bullets only for genuine enumerations (contributions, assumptions, datasets);
   never end a section with a summary of itself.
6. **Front matter rules**: title ≤ 14 words, at most one colon, no question mark, no
   keyword stuffing; abstract is one paragraph with arc problem → gap → approach → main
   quantitative result → implication, no bullet-like sentence lists.
7. **LaTeX rules**: sections live in `paper/sections/NN_slug.tex` (no `\documentclass`
   there); figures referenced as `figures/<slug>.pdf` with `\label{fig:<slug>}`; captions
   state the takeaway, not what the axes are; `\todobox{...}` environment is defined in
   main.tex; keep packages minimal.

## 7. main.tex skeleton (helpers.main_tex_skeleton)

`\documentclass[11pt]{article}`; packages: geometry (margin=1in), amsmath, amssymb,
graphicx (+`\graphicspath{{figures/}}`), booktabs, xcolor, tcolorbox, natbib
(numbers,sort&compress), hyperref (last). Define:
```tex
\newtcolorbox{todoboxenv}{colback=yellow!8,colframe=orange!70!black,title=TODO,fonttitle=\bfseries}
\newcommand{\todobox}[1]{\begin{todoboxenv}#1\end{todoboxenv}}
```
`\title{...}` `\author{Author Name\thanks{Draft generated for author revision.}}`,
`\date{}`, `\maketitle`, `\begin{abstract}...\end{abstract}`, one `\input{sections/NN_slug}`
per section (no extension), `\bibliographystyle{plainnat}` + `\bibliography{refs}`.
Escape nothing in title/abstract beyond `%`, `&`, `#` → `\%`, `\&`, `\#`.

## 8. Deterministic slop linter (helpers.slop_lint)

Scan `paper/main.tex` + `paper/sections/*.tex`, skipping comment lines (`%`-led) and the
preamble of main.tex (start at `\begin{document}`). Rules (rule ids in SlopViolation.rule):
- `em_dash`: any `—` or ` --- ` occurrence (per line).
- `banned_phrase:<word>`: case-insensitive matches of the banned-phrase list (single occurrences
  flagged for hard-banned words; threshold words flagged only beyond their allowance).
- `not_x_but_y`: regex `\bnot only\b.{0,80}\bbut also\b` (DOTALL within paragraph).
- `heading_depth`: each `\subsubsection`.
- `heading_density`: file whose `\subsection` count > 4.
- `bullet_misuse`: `itemize`/`enumerate` inside files whose slug contains intro/discussion/
  conclusion/related.
- `rhythm_uniform`: per file, sentences = split on `[.!?]` of de-LaTeXed text; if ≥ 10
  sentences and stdev(word counts) < 4.0 → one violation.
- `paragraph_uniform`: per file, paragraphs = blank-line splits; if ≥ 6 paragraphs and
  stdev/mean of word counts < 0.25 → one violation.
- `title_shape`: from `\title{...}`: > 14 words, > 1 colon, ends with `?`.
Score: `max(0.0, 1.0 - 0.02 * total_violations)`, weights not needed in v1.
De-LaTeX for rhythm rules: strip commands `\\[a-zA-Z]+(\[[^\]]*\])?(\{[^}]*\})?`, math `$...$`.

## 9. Error handling policy

- `.ai()` wrapped: except Exception → `helpers.safe_ai_fallback(SchemaCls, ...)` and log
  via `print` (agentfield captures stdout); orchestrators treat `confident=False` results
  as usable-but-degraded, never crash the run.
- harness wrapped: check `result.is_error` / `result.parsed is None`; degrade to
  WorkerResult(status="failed", summary=error_message) etc. Verify on-disk effects after
  every harness call (files exist / pdf compiled) — never trust the transcript.
- The ONLY hard failure that aborts the run: blueprint failure or workspace creation failure.

## 10. Runtime

AGENTFIELD_SERVER=http://localhost:8080). OpenCode CLI on PATH, OPENROUTER_API_KEY in env.
latexmk from MacTeX. venv has matplotlib/numpy/pandas for figure scripts.
Env knobs: `OPENCODE_MAX_CONCURRENT` (default 10), `AGENTFIELD_HARNESS_TIMEOUT_SECONDS`
